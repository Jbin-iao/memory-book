# 记忆册功能升级 · 2026-10-28

本版沿用静态 HTML / CSS / JavaScript 与现有 Supabase 表，不需要安装运行依赖或修改数据库结构。

## 功能

- 时间线支持全文与地点搜索、月份筛选、标签筛选、只看收藏及重置；支持中文逗号分隔标签。
- 日历支持按月切换、返回本月、显示每天的记录数量和当天回忆。
- 首页优先展示往年同月同日记录；无匹配时显示明确标注的本月回顾，不把随机记录当作往年今日。
- 输入文字、日期、地点、标签、收藏，以及添加或移除照片时自动保存当前草稿；刷新后可继续写或丢弃。草稿仅在当前浏览器保留。
- 显示本地保存、同步中、已同步、配置缺失及失败重试状态。恢复网络或重新聚焦页面时尝试同步。

## 同步与兼容

- 三方合并使用上次成功同步的基线、本地记录及最新云端记录；独立修改合并，同条记录的不同修改保留冲突副本，编辑与删除冲突保留编辑内容。
- 更新现有云端归档时使用 `updated_at` 条件更新，发现版本变化后重新读取和合并，最多重试四次。新归档使用插入与唯一键冲突重试。
- 网络请求期间的新编辑不会被返回结果覆盖，仍待同步时继续提交；支持 Web Locks 的浏览器会串行执行同账号跨标签页同步。
- 编辑窗口或恢复草稿的内容落后于最新本地版本时，保存会保留新版本副本；删除过期版本会被拒绝，要求重新打开。
- 各账号和访客使用独立本地记录、同步基线和草稿。旧版公共浏览器记录保留在访客空间，不自动上传到任意登录账号。需要转移时，退出登录导出，再登录导入。
- JSON v1 备份继续兼容；新增 `tags`、`favorite`、`conflict` 字段，旧记录自动补默认值。
- 仍使用 localStorage 存储压缩照片，每条最多三张；存储不足会报错，不主动清理回忆。基线和草稿也占用本地容量。

当前本地 `assets/js/supabase-config.js` 的 `anonKey` 为空，因此真实云同步未启用。本次以模拟服务验证同步算法及并发行为，没有连接生产数据。配置公钥后应使用两个测试账号、两台设备验证 RLS、登录切换和网络恢复。所有设备应更新到本版；旧版客户端的无条件覆盖写入不受新版条件更新保护。
